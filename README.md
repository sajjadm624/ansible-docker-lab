# ansible-docker-lab
## Docker-Based Ansible Lab for Hands-On Practice

This repository provides a complete, lightweight Docker-based lab setup for practicing Ansible on a personal computer. It includes:

Step-by-step instructions to spin up minimal Alpine Linux containers as Ansible nodes

Fully configured SSH access, including password and key-based authentication

Ready-to-use inventory.ini, ansible.cfg, and sample playbooks

Guidance on avoiding common pitfalls (SSH errors, host key checking, Python interpreter issues)

Optional scripts for automating lab setup and teardown

Perfect for DevOps engineers, students, or anyone looking to learn Ansible in a reproducible, resource-efficient lab environment on macOS, Linux, or Windows (with Docker).
